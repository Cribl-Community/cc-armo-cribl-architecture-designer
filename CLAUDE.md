## Claude Code — Capra pages

You do not have Capra memorized. Before any UI/page work:
1. WebFetch <https://capra.cribl.io/llms.txt>
2. Follow the absolute Page Templates URL from that index (WebFetch it).
3. Follow the absolute URL for the chosen template page.

Do not implement a page from generic React/frontend patterns. If the template is unclear, ask.

If WebFetch is unavailable, fall back to `curl -fsSL <url>` via Bash for the same fetches.
